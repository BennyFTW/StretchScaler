# Contributing

Thanks for helping out.

**Bugs:** use the bug report template and paste your `StretchScaler.log`. It gets overwritten every time the
app starts, so copy it right after the problem happens. Your GPU, monitors and H1Z1 display settings help a lot.

**Testing:** if you try it on AMD/Intel, other refresh rates or other games, open an issue and say how it went.

**Pull requests:** build with `build.bat`, keep changes focused, and say how you tested. One hard rule: it stays
external. No DLL injection, hooking or reading game memory.
